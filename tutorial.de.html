Hallo,
willkommen bei VSDactyl.

Mit VSDactyl verwaltest du Dateien und Konsole deiner Remote-Server direkt in VS Code - schnell, sicher und im SansCraft-Design.

Schnelle Installation

1

Extension Marketplace öffnen

Nutze Ctrl + Shift + X unter Windows/Linux oder Cmd + Shift + X unter macOS.

Nach VSDactyl suchen, Install klicken und die VSDactyl-Ansicht in der Activity Bar öffnen.

Erste Verbindung

API-Key erstellen

  1. Panel-Dashboard öffnen.
  2. Zu Account gehen.
  3. API Credentials öffnen.
  4. Neuen Key erstellen und kopieren.

In VS Code hinzufügen

  • Display Name: Freier Name.
  • Panel URL: Adresse deines Panels.
  • API Key: Den kopierten Schlüssel einfügen.

SSH Auto-Setup

Tipp: SSH-Key ist sicherer und stabiler als Passwort-Anmeldung.

Ein-Klick-Einrichtung

Im Formular SSH Key wählen und Auto-configure SSH Key aktivieren.

  • Lokales Schlüsselpaar wird erzeugt.
  • Öffentlicher Schlüssel wird im Panel hinterlegt.
  • Privater Schlüsselpfad wird direkt gespeichert.

Dateien wie lokal verwalten

Verbinden und bearbeiten

Server rechtsklicken und Connect (SFTP) wählen. Danach kannst du Dateien direkt im Explorer bearbeiten, speichern, hochladen und organisieren.

Server-Terminal

Über Open Terminal im Server-Kontextmenü erhältst du Logs und Befehle direkt in VS Code.

Unterstützt Live-Konsole und schnelle Befehlsausführung in einem Workflow.

Fehlerbehebung

Authentifizierungs- oder Schlüsselprobleme

SSH-Key per Auto-Setup neu erstellen und Kontodaten in den VSDactyl-Einstellungen prüfen.
