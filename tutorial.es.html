Hola,
bienvenido a VSDactyl.

VSDactyl te permite gestionar archivos y consola de servidores remotos directamente en VS Code, con un flujo rápido y seguro.

Instalación rápida

1

Abrir el Marketplace de extensiones

Usa Ctrl + Shift + X en Windows/Linux o Cmd + Shift + X en macOS.

Busca VSDactyl, haz clic en Install y abre la vista de VSDactyl en la barra lateral.

Primera conexión

Crear una API Key

  1. Abre el panel.
  2. Ve a Account.
  3. Abre API Credentials.
  4. Crea una nueva clave y cópiala.

Añadirla en VS Code

  • Display Name: Nombre libre.
  • Panel URL: Dirección de tu panel.
  • API Key: Pega la clave copiada.

SSH Auto-Setup

Consejo: La autenticación por clave SSH es más segura y estable que la contraseña.

Configuración con un clic

En el formulario, selecciona SSH Key y activa Auto-configure SSH Key.

  • Genera un par de claves localmente.
  • Sube la clave pública al panel.
  • Guarda la ruta de la clave privada para uso inmediato.

Gestiona archivos como si fueran locales

Conectar y editar

Haz clic derecho en un servidor y elige Connect (SFTP). Después puedes editar, guardar, subir y organizar archivos desde Explorer.

Live Production Auto-Sync

Deployment Syncing

Instead of manually uploading files, you can bind a local folder directly to a remote server. Right-click any Pterodactyl server and choose VSDactyl: Map Local Folder (Auto-Sync). Select your local workspace folder.

VSDactyl will drop a .vsdactyl-sync.json configuration file there and immediately start watching the folder. Any changes you make (saves, deletes, new plugins) will instantly be tunneled to the server in the background!

Transferencias Masivas Asistidas por Archivo

Subidas Ultrarrápidas

Arrastra y suelta una carpeta enorme directamente en un nodo del servidor. VSDactyl intercepta automáticamente la acción, comprime los archivos en un solo archivo, lo sube a través de SFTP y lo extrae instantáneamente en el servidor remoto.

Consejo: Monitorea las velocidades de subida en vivo, establece límites activos y revisa los tiempos estimados restantes mediante el panel Transfer Manager Dashboard a través del ícono de sincronización en la parte superior de la Vista del Servidor.

Consola y Vista Web

Terminal en Vivo y Telemetría

Monitorea las métricas en vivo de CPU, RAM y Disco de tu servidor directamente en la vista de árbol. Haz clic derecho en cualquier servidor y selecciona Open Terminal para streaming de consola en tiempo real.

Panel Web Integrado

¡Elige Open Panel in Web View para cargar sin problemas la interfaz completa de Pterodactyl en una pestaña dedicada de VS Code!

Solución de problemas

Problemas de autenticación o claves

Regenera la clave SSH con auto-setup y verifica los datos de cuenta en la configuración de VSDactyl.
